# ZDC Systems — лендинг

Статическая страница проекта для GitHub Pages: без сборки и зависимостей —
`index.html`, `style.css`, `app.js`, `i18n.js` и скриншоты дашборда в `assets/`.

## Что внутри

- **Hero** — поле кода на `<canvas>`, по которому идёт луч сканера и подсвечивает
  уязвимые строки; заголовок «расшифровывается»; справа — живой журнал воркера.
- **Демо-скан** — Flask-приложение, по которому проходит сканер: находки по
  критичности, токен GitHub вычищается `redact` прямо на глазах. Токен
  генерируется в браузере — в репозитории нет ничего похожего на настоящий секрет.
- **Режимы**, **конвейер** (SVG с бегущими пакетами, описание узла по наведению),
  **песочница пентеста**, **орбита провайдеров** (локально / облако),
  **галерея** скриншотов — переключается вместе с темой, **принципы** (карточки
  переворачиваются), **развитие проекта** — хроника по датам из журнала разработки
  (линия заполняется при прокрутке, фильтр по направлениям, скриншоты увеличиваются),
  **локальная версия и сотрудничество** — как проходит внедрение и почта для
  предложений (misanaproger@gmail.com и ziron0901@gmail.com; кнопка «Связаться» в шапке
  пишет обоим, CTA в финале, подвал) и объявления «демо-режим доступен всем» /
  «лицензионные ключи — скоро».
- **Страница «Установка»** (`install.html` + `install.js`) — скачивание комплекта из
  открытого репозитория `ZDC-System/ZDC-bin-release` и инструкция запуска (setup → start →
  вход по `API_TOKEN`, демо-режим включён по умолчанию, `DEMO_MODE=0` выключает, нейросеть, команды). Ссылки в разметке
  ведут на архив ветки `main`; скрипт при загрузке спрашивает GitHub API — если появится
  релиз, кнопки переключатся на его архив, — и показывает версию/glibc из `VERSION`.
  Без сети или при лимите API (60 запросов/ч с адреса) остаются ссылки на `main`.
- Скриншоты — только настоящие снимки дашборда (Playwright, `pitch/scripts/shots.mjs`)
  без макетов устройств; данные на них — демонстрационные (`pitch/scripts/seed.py`).
- Языки RU / EN / UZ (`i18n.js`; язык браузера по умолчанию), светлая и тёмная
  тема, `prefers-reduced-motion`, адаптив до 360px.
- Пасхалка: код Konami (↑ ↑ ↓ ↓ ← → ← → B A) или клик по нему в подвале.

## Локально

```bash
python3 -m http.server 8000   # http://localhost:8000
```

## Публикация

1. Создать репозиторий (например, `ZDC-Systems/zdc-systems.github.io` — тогда адрес
   будет `https://zdc-systems.github.io/`, или любой другой — `…/имя-репо/`).
2. Запушить содержимое каталога в `main`.
3. Settings → Pages → Source: **GitHub Actions**. Workflow `.github/workflows/pages.yml`
   публикует страницу при каждом пуше.

Все пути относительные, поэтому страница работает и в корне домена, и в подкаталоге.
Скриншоты пересобираются: стенд (Postgres + `analitics_service` с `DASHBOARD_DIR`,
`API_TOKEN`; демо включён по умолчанию), `python3 pitch/scripts/seed.py` → JSON с id отчётов,
`BASE=http://127.0.0.1:<DASHBOARD_BIND> node pitch/scripts/shots.mjs '<json>'` → PNG
(в т. ч. `*-demo` — форма демо-режима), затем webp: 1600×1000, телефон — 560×1212
(`assets/shots/{light,dark}-<имя>.webp`).
