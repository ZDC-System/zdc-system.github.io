    02 / три режима
    
        
    Код, инфраструктура, живая атака
    
      
    
      
    
        
    
          
    
            
          
    
          code_review
          
    Ревью кода
    
          
    Нейросеть сама выбирает файлы, читает проект частями с картой всех файлов — и не путает «нет аутентификации» с middleware в соседнем модуле. Плюс gitleaks, semgrep, cargo-audit.
    
          
    • SQLi · RCE · IDOR
    • секреты в истории
    • уязвимые зависимости
    
        
    
        
    
          
    
            
          
    
          deploy_review
          
    Ревью развёртки
    
          
    Dockerfile, compose, Kubernetes/Helm, Terraform, CI/CD, nginx. Свои правила и hadolint, tfsec, kube-score, checkov — нейросеть подтверждает и объясняет.
    
          
    • privileged · docker.sock
    • root и образы без версии
    • actions без SHA
    
        
    
        
    
          
    
            
    
          
    
          pentest
          
    Пентест в песочнице
    
          
    Нейросеть сама пишет Dockerfile, поднимает копию сервиса с базой рядом, ставит себе инструменты и атакует — nuclei плюс агентный цикл. Только по подписанному scope.
    
          
    • авторазвёртка с самоисправлением
    • nuclei · curl · sqlmap…
    • песочница сносится всегда

    07 / паранойя по умолчанию
    
        
    Инструмент безопасности, который сам безопасен
    
      
    
      
    
        
    fail-closedНеизвестный маршрут — 404, без токена сервер не стартует.
    POST /reports/%63laim
    → 403 Forbidden
    
        
    redactТокены, пароли в URL, *.env — вычищаются до модели.
    DATABASE_URL=postgres://u:***@db
    GITHUB_TOKEN=***
    
        
    scopeПодписанный scope или цель с истекающим сроком.
    scope: target not authorized
    → pentest skipped
    
        
    audit-logКаждое активное действие — в файл и в БД.
    {"tool":"pentest.web_scan",
     "target":"http://target:8000"}
    
        
    brute-force10 неудач за 5 минут — 429, счётчик в Postgres переживает рестарт.
    HTTP/1.1 429 Too Many Requests
    Retry-After: 300
    
        
    least privilegeРоли user/worker, образы не от root, actions по SHA.
    USER oxs (10001)
    permissions: contents: read
